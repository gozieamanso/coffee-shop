# Coffee Shop
A responsive coffee shop website built with HTML5 and vanilla CSS. The project features a modern landing page for a coffee shop, with sections introducing the business, showcasing its menu, displaying customer testimonials, presenting a photo gallery, and providing contact information.

## Features
- Responsive Navigation: Navigation links for desktop screens and a hamburger menu button for smaller screens.
- Hero Section: An introductory section highlighting the coffee shop with call-to-action buttons.
- About Section: Information about the coffee shop and its social media links.
- Menu Section: A grid displaying different food and beverage categories.
- Testimonials: A section showcasing customer feedback.
- Gallery: A collection of images presented in a responsive grid layout.
- Contact Section: Displays contact information alongside a contact form.
- Responsive Layout: Adapts to different screen sizes using CSS media queries.
- Smooth Scrolling: Enables smooth navigation between sections.
- CSS Variables: Uses custom properties for consistent colors and easier styling.
- Accessibility Considerations: Includes descriptive image alt attributes and visible keyboard focus indicators.
